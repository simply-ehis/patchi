WHAT IS PATCHI

One colony, not one scanner

Patchi isn’t a linter. It’s a colony of 54+ specialist agents orchestrated by a Brain that understands your code as a graph. Static + dynamic + AI, with a risk gate that never auto-fixes what it shouldn’t.

Static, but structural

Tree-sitter AST across Python, JS/TS, Rust, Go, Java, C/C++, Swift, Ruby, Svelte, etc. Import graph, symbol graph, route mapper (18 frameworks), circular deps, orphan files. Incremental via git diff + hash cache.

4 tiers: Ollama (offline) → API keys → Free keys → AI Horde
14 providers: OpenAI, Anthropic, Google, Groq, Mistral, Cohere, Together, Fireworks, Perplexity, OpenRouter, DeepSeek, xAI, NVIDIA, HF + custom OpenAI-compat

AI when you want it

Without AI: pure static analysis, zero cost. With AI: fix generation, council deliberation, NL queries. Keys in .patchi/keys.json, never sent elsewhere. Local Ollama is first-class.

Fixes that verify

Every patch is risk-gated, snapshotted (atomic rollback), tested, then re-checked by the same agents. 174s → 0.1s cached security report via deduplication + OWASP correlation.

How it’s different
  • Graph-first, not list-first (like Wiz Security Graph, but for code)
  • Toxic combos, not single alerts — composite risk findings
  • Learning brain — tracks accept/reject, stops nagging
  • Governor pipeline — phase-gated, crash-recoverable (p scan --governor)
Safety by design
  • confirm (default) · auto (low-risk auto) · autopilot (full trust)
  • Snapshot + undo/redo, atomic writes, file-locked queue
  • Pre-1.0.0 — APIs may evolve, .patchi is best-effort forward-compat
  • Hosted live guard is experimental (bannered)
BRAIN

The Brain is the database

Wiz modeled cloud as a graph; Patchi models your code as one. Every file, route, dependency, and layer (L1 modules → L4 project) mapped. Click any node → full context, blast radius, history. Powers everything else.

  • 9-language AST walkers + 18-framework route detectors
  • Import graph (Tarjan cycle detection), symbol graph, layers, DOT export
  • Tap-to-spawn — max 5 ants, 10s cooldown, 60s expiry, 3 per node
  • Blast radius, git blame, drift, health 0–100 (A–F)
