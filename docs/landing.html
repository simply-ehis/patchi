The Colony Structure

Every file is a node. Scouts move through them one by one,
flagging what needs attention, while workers patch it before
the scan finishes.

The colony's structure is visible now. Files as nodes, dependencies as edges, the entire nest mapped in amber light. Scouts range across your codebase — 20 security agents covering TaintAnalyzer, SecretScanner, ConfigAuditAgent, InjectionAgent, AuthZAgent, CryptoAgent, and more — flagging what needs attention. Workers patch it before the scan finishes. What was raw text in the CLI is now a living graph you can read at a glance.

Patchi's agents run in parallel via a ThreadPoolExecutor coordinator. The orchestrator deduplicates findings, correlates across agents, and assigns composite risk scores. Every fix is re-scanned to verify the finding is actually gone. No other coding agent does this.

Defended Territory

Your repos are watched constantly, around the clock.

Hosted mode is continuous, self-hosted, always-on defense. The colony guards your territory around the clock — and critically, hosting is user-controlled. Patchi does not run anyone's code on its own servers. You own the infrastructure. You own the data. The soldiers stand guard on your machines, not ours.

The colony grows its structure over time. Every scan feeds the test loop. Every fix sharpens the rules. The pheromone trail of findings makes the next scout faster, the next worker more precise.

Continuous CVE monitoring watches NVD, GHSA, and OSV feeds. When a new vulnerability drops, Patchi re-scans your dependencies automatically and alerts via your configured channels. The colony never sleeps because threats never sleep.
